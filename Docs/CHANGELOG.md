# Official changelog for `CMOS pre-alpha version 0.0.3`

## WHAT'S NEW????

1. **Fixed PIT initialization log bug**

   * Resolved an issue where the message `PIT initialized at 100 Hz` was not displayed correctly.
   * Boot logging system now properly prints all initialization statuses.
   * Improved debugging visibility during kernel startup.

2. **Reworked folder structure**

   * Reorganized project directories for better readability and scalability.
   * Kernel, HAL, drivers, and architecture-specific code are now separated more cleanly.
   * Simplifies future module expansion and maintenance.

3. **Project renamed to `CMOS`**

   * Changed the operating system name from `COSMOS-C` to `CMOS`.
   * Updated folder names, include paths, and internal references.
   * Provides a shorter and cleaner project identity.

4. **Removed autogenerated code**

   * Deleted code previously generated by ChatGPT.
   * Replaced autogenerated implementations with handwritten code.
   * Improves code quality, understanding, and maintainability.

5. **Updated boot success color**

   * Changed successful initialization messages from light green to yellow.
   * Improves readability on VGA text mode displays.
   * Makes boot logs visually more consistent.

6. **Created `CONTRIBUTING.md`**

   * Added contribution guidelines for developers.
   * Includes project rules, contribution workflow, and coding standards.
   * Makes onboarding easier for new contributors.
